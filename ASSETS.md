# The Polish Haus: Asset Library

Every photo, logo, font and brand colour for the site is listed here. Check this file
before asking for an upload: if an asset is listed, it is already in the project.

## Folders

| Folder | What lives there | Served on the site? |
|---|---|---|
| `public/images/photos/` | Web-sized JPGs (1400px wide, ~90–260 KB). Reference as `/images/photos/<name>.jpg`. | Yes |
| `public/images/` | Logos (transparent PNG), generated by `scripts/make-logos.mjs` | Yes |
| `public/fonts/` | Brand fonts | Yes |
| `assets/originals/photos/` | Full-resolution masters of the photos. Re-export from these, never from the web JPGs. | No |
| `assets/inbox/` | Drop new photos here, then run `node scripts/add-photos.mjs` | No |

### Adding new photos
1. Put the files in `assets/inbox/` (or attach them in chat and ask for them to be added).
2. Run `node scripts/add-photos.mjs` (optionally `photo1.png=new-name` to rename).
3. Add a row to the table below.

## Logos (`public/images/`, transparent PNG)

Current brand (Oct 2026): "PH" monogram in a ring, "THE POLISH HAUS", tagline "NAILS • BEAUTY • SELF CARE".
The site uses the client's gold. A metallic pink recolour (brightness mapped onto a wine → pink → blush ramp) was tried and kept as an alternative.
Master: `assets/originals/logos/logo-gold-glow.png` (1536×1024, transparent; the glow in the colour channels is hidden by the alpha).
All four files are generated from it with `node scripts/make-logos.mjs`. The nav wordmark has its strokes thinned
(alpha erosion) because the bold caps read too heavy at nav size; the `thin()` settings are in that script.

| File | What it is | Size | Use on |
|---|---|---|---|
| `logo.png` | Full lockup: monogram, name, tagline, star divider (gold) | 1195×993 | Footer, large brand moments |
| `logo-wordmark.png` | "THE POLISH HAUS" only, cropped from the lockup (gold, lighter strokes) | 1195×196 | Navigation |
| `logo-pink.png` | Full lockup, metallic pink | 1195×993 | Not used (alternative) |
| `logo-wordmark-pink.png` | Wordmark, metallic pink, lighter strokes | 1195×196 | Not used (alternative) |

The previous rose-gold logos (TPH monogram lockup, wordmark, white wordmark) are kept in `assets/originals/logos/old/`.
No white/dark-background version, monogram-only file or favicon exists yet (`app/favicon.ico` is the Next.js default).
